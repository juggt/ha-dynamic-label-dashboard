# MVP Scope

## Included

- One dashboard
- Home Assistant custom component
- Dynamic room grouping by areas
- Floor-based room sorting
- Label-based inclusion rules
- Separate global label selection for summary and detail
- Detail grouping by label order
- Room overrides for add/hide/reorder behavior
- `Ohne Raum` fallback group
- Desktop drawer detail view
- Mobile collapsible room sections
- Automatic updates when source data changes

## Excluded from MVP

- Multiple dashboards
- Per-user preferences
- Manual pinning of items
- Advanced label metadata rules
- Drag-and-drop dashboard editor
- Rich analytics/history widgets
- Custom theme engine

## User experience summary

### Overview page
- room cards only for rooms with matching items
- summary items shown individually
- summary content chosen via label configuration
- mini controls allowed in cards
- amount displayed should fit available layout

### Detail view
- grouped by labels
- only non-empty groups shown
- desktop drawer
- mobile inline/collapsible behavior
